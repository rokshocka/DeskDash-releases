# DeskDash releases

DeskDash turns a tablet or phone into a control panel for your Windows PC: audio and Voicemeeter, Discord, OBS,
game buttons, lights and Home Assistant, hardware sensors, and more. Everything stays on your home network.

This page only holds the downloads. **[Get the latest release →](https://github.com/rokshocka/DeskDash-releases/releases/latest)**

## Install

1. Download `deskdash.exe` from the latest release and run it. Windows may warn that it's from an unknown publisher
   (it isn't code-signed yet): choose **More info › Run anyway**.
2. Choose **Yes** to install: DeskDash goes in your user folder (no admin needed), appears in the Start menu, and
   starts with Windows. If the firewall asks, allow it on **Private** networks.
3. Its setup page opens: scan the QR code with your tablet or phone.

To remove it: Settings › Apps › Installed apps › DeskDash › Uninstall.

## Updates

DeskDash checks this page for new versions. When one is out, the tray menu, the setup page and your tablets offer
**Update**; DeskDash downloads it, checks its signature, and restarts on the new version. **Go back to …** undoes an
update.
